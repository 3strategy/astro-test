# Binary search

Binary search finds a target in a **sorted list**. Start in the middle.
If the target is smaller, search the left half. If it’s larger, search
the right half. Repeat until you find it or run out of values.

## Try it

Search for **42**. Before clicking **Step**, predict which half will
remain. Then try **24**, which isn’t in the list.
